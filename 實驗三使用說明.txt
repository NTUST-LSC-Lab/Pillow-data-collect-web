實驗三 Web 預覽版

檔案位置
- spp3_BLE/index.html：完整實驗 Web（實驗一、二保留，新增實驗三）。
- spp3_BLE/preview.html：不需要 ESP32 的模擬操作預覽。
- 啟動預覽.command：雙擊啟動 localhost:8083，並開啟模擬預覽。

預覽方式
可直接用 Chrome 開啟 spp3_BLE/preview.html。
也可雙擊「啟動預覽.command」，或在本資料夾執行：
  python3 -m http.server 8083 --bind 127.0.0.1
模擬預覽：http://localhost:8083/spp3_BLE/preview.html
完整 Web：http://localhost:8083/spp3_BLE/
模擬頁的資料與建議高度均為示範，下載檔名加上 DEMO_；不會連線或控制硬體。

操作流程
1. 在完整 Web 上方輸入性別、年齡、身高、體重，連線 BLE。
2. 在實驗專區選擇實驗 03，選受試者編號與儲存資料夾。
3. 沿用實驗二的介面校正姿勢一與姿勢五。姿勢五帶入裝置建議高度，操作者可調整 Head／Neck。
   實驗三會先同步個人資料，再讀取裝置建議；按校正完成時同步建立韌體分類 anchor，期間保持指定姿勢。
4. 按「截圖並儲存校正總覽」。成功儲存後只啟用「受試者已離枕，開始抽乾」。取消或失敗不解鎖。
5. 請受試者離枕，再按「受試者已離枕，開始抽乾」。裝置完成並回覆相符的 DRAINED 後，才啟用「套用姿勢一高度，準備測試」。按下後從空氣囊充氣至姿勢一校正高度，待裝置到位，再勾選離枕確認並請受試者躺下。
6. 選本輪睡姿，確認受試者離枕。頭部重新接觸枕頭時立即按「開始記錄 15 秒」。
7. 滿 15 秒自動停止，再按「完成本輪」。換另一姿勢；兩種睡姿均保持姿勢一高度。
8. 查看第 3、5、10、15 秒分類比較，按「儲存結果總覽＋CSV」。重測會保留各輪。

記錄定義
- 起點是瀏覽器按開始的時間，包含操作者反應與 BLE 啟動延遲。
- 每輪 CLASSIFY,START 會依現有韌體行為重置分類平滑歷史；PRED／LEGACY 關閉。
- 顯示韌體平滑標籤（原始標籤）；不把數字姿勢直接轉成韌體標籤以推定正誤。
- 第 n 秒使用 (n-1, n] 秒間最後收到的分類。缺資料不沿用前一秒。
- 壓力與分類不是同一次同步取樣。CSV 分別保存事件、時間與欄位，不假裝同時量測。
- 固定高度是韌體依充放氣時間估計，並非實測高度。
- 若變更個人資料，可按「重新建立此受試者校正」重新校正與儲存總覽。
- 斷線後需重新建立分類校正；不會自行恢復記錄或重送充氣。
- 所有資料暫存在本頁記憶體，離開前務必儲存。CSV 包含受試者資料，請使用自己的資料夾妥善保存。

驗證
Web 回歸測試共 145 項通過，包含抽乾 ACK 不解鎖、相符 DRAINED 解鎖、充氣完成才開放勾選、停止及舊韌體拒絕。
新增測試包含：實際總覽寫入成功／失敗／取消的解鎖回呼、固定高度、15 秒記錄、缺值與斷線。
本環境限制啟動瀏覽器與本機伺服器，因此未完成實際畫面渲染與 Web Bluetooth／ESP32 驗證。
必須搭配同層 ipillow-experiment03/node32_ipillow_3_BLE/ 的新韌體。已修改原始碼並編譯，尚未燒錄或實機測試。
新增 EXP02,DRAIN 與 HEIGHT_DRY 流程；舊韌體不支援，Web 會維持準備按鈕停用。抽乾不是由 Web 計時認定完成。
