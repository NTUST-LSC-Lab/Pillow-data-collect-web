## 啟動與共同準備

在專案根目錄執行：

```sh
python3 -m http.server 8083 --bind 127.0.0.1
```

以桌面 Chrome／Edge 開啟 `http://localhost:8083/spp3_BLE/`，用正式頁面連接 BLE 並選擇本機儲存資料夾。雙擊 [啟動預覽.command](啟動預覽.command) 會啟動同一連接埠並開啟實驗04模擬頁；模擬資料不可混入正式實驗。

1. 讓受測者離枕，連接裝置，等待開機及氣囊動作完成。
2. 填寫使用者資料，在實驗區選擇受測者編號 `S01～S10` 與儲存資料夾。
3. 在要執行的實驗區完成姿勢一、姿勢五校正；依視窗微調高度、確認穩定，再按「校正完成」。不同實驗的校正不可假設已自動共用。
4. 保存校正總覽，再依該實驗流程開始。Head 範圍為7～16 cm、Neck為10～14 cm，每次微調0.5 cm。

校正與未儲存的輪次暫存在頁面中；離開或重新整理前請確認檔案已保存。目前沒有從舊校正檔直接恢復 ESP32 模型基準的功能。

## 實驗總覽

| 實驗 | 已實作內容 | 記錄／完成規則 |
| --- | --- | --- |
| 01 | 固定睡姿的穩定／微動辨識 | 每條件35秒，至少30筆有效無歷史分類才算完成 |
| 02 | R／M／A／I支撐方法與舒適度比較 | 各姿勢四種方法，手動保存空枕／躺回壓力快照與評分 |
| 03 | 躺下後20秒雙模型姿勢辨識 | 固定姿勢一校正高度，分別測姿勢一與五 |
| 04 | 兩高度、五睡姿躺枕／離枕偵測 | 每睡姿躺枕30秒，隨後離枕30秒 |
| 05～09 | 預留區塊 | 尚未設定操作流程 |

實驗01／03的分類結果為 **Group1＝姿勢一、二；Group2＝姿勢三、四、五**，不是五種睡姿各自的分類結果。實際睡姿由操作者選擇／標記。

### 實驗01：四條件逐輪保存

兩姿勢校正均需取得 ESP32 的五筆有效新資料平均。校正卡片及總覽顯示模型實際保存的同一組平均，不用按鈕當下的單筆壓力取代。

| 操作順序 | 條件編號 | 內容 |
| --- | --- | --- |
| 1 | 03 | 姿勢五高度、姿勢五穩定／自然呼吸 |
| 2 | 04 | 姿勢五高度、姿勢五微動／自然呼吸 |
| 3 | 高度切換 | 前兩輪完成並儲存後，受測者完全離枕，執行「重新執行開機流程並套用姿勢一滿分高度」 |
| 4 | 01 | 姿勢一高度、姿勢一穩定／自然呼吸 |
| 5 | 02 | 姿勢一高度、姿勢一微動／自然呼吸 |

每輪確認條件與高度並勾選確認。按「開始辨識」只準備功能；按「開始記錄」、收到裝置啟動確認後，才開始顯示及保存該輪35秒資料。

35秒內至少30筆有效無歷史分類才算完成；不足不以舊結果湊數。缺筆最多額外等待3秒補取原結果，不把補取當成新推論。每條件保存CSV＋PNG後再前進；中斷資料可以保存，但不算完成。重測使用「重新測試本輪」，先確認原檔已保存。

高度切換使用 `STARTUP_HEIGHT` 流程：重新執行開機抽／充氣，再套用已保存的姿勢一高度；不清除兩組校正基準。記錄期間暫停背景 `DEBUG`／`I` 查詢，結束後恢復。

### 實驗02：四種方法比較

完成姿勢一／五校正快照後，分別測試 R（論文補償）、M（30人平均補償）、A（兩者比例平均）、I（校正控制高度），共八組條件。

每次確認離枕後選方法，等待裝置抽乾、充氣完成；保持空枕並記錄穩定壓力，再以指定姿勢躺回、記錄壓力、選擇0～10分滿意度，最後保存本次結果SVG。可在支撐設定仍符合條件時重新記錄壓力，不會因此重新打氣；重記空枕後須再記躺回與評分。

R／M／A將補償後的目標ADC換算為固定充氣時間；I使用校正高度。兩姿勢校正及空枕／躺回結果為單筆壓力快照，不是模型五筆平均。計算比例、時間與上限定義見 [comfort-experiment.js](spp3_BLE/comfort-experiment.js)。

### 實驗03：固定高度20秒雙模型

1. 依序完成姿勢一、姿勢五的五筆模型校正，並保存校正總覽。
2. 確認受測者離枕，按「受試者已離枕，抽乾並恢復開機高度」，完成後按「套用姿勢一高度，準備測試」。
3. 選本輪姿勢一或五，確認離枕；頭部接觸枕頭時按「開始記錄20秒」。兩種睡姿均維持姿勢一校正高度。
4. 從按開始起20秒自動停止記錄及分類；按「完成本輪」確認，再離枕、選姿勢並重測或測下一輪。重測新增輪次。
5. 按「儲存CSV、結果總覽與壓力曲線」，保存本頁該受測者的所有輪次。

校正須確認五筆模式的ACK、完成狀態、品質、裝置基準及高度才保存。卡片、總覽及CSV的校正壓力均使用裝置讀回的五筆平均；五筆不代表必定五秒完成。逾時不覆蓋舊卡片，須等取消／高度恢復完成、新壓力到達並重新確認後重試。

每秒採Web接收區間內最後一筆新序號分類。滿20秒不代表20筆全部有效；分類啟動延遲、暖機、無效與缺資料仍須查看逐秒表及CSV。

### 實驗04：兩高度躺枕／離枕

兩姿勢校正保存各自高度與單筆有人壓力快照。先測姿勢五高度，再確認受測者離枕，按「抽乾並設定姿勢一高度」，完成後測姿勢一高度。此切換使用 `DRAIN` → 恢復開機高度 → `HEIGHT_DRY`，保留兩組校正，不重新啟動處理器。

每個高度先按「開始…高度測試」啟用狀態按鈕，**第一次按睡姿才開始記錄**，沒有初始空枕30秒。依序執行姿勢一至五，每次躺枕30秒、完全離枕後按「離開枕頭」再記30秒；最後顯示5／5完成，按「結束本高度測試」。兩高度固定停留共10分鐘，校正、充放氣與動作另計。

狀態按鈕只提供實際標記，不改變高度。滿30秒不自動切換；重複按相同狀態不重設計時。提前切換、錯序與補測均保留，只有待測睡姿及其後離枕都滿30秒才推進進度。分段CSV只取每段前30秒，連續CSV持續記錄等待時間及判定，直到本輪結束／中止。

判定比例＝目前壓力kPa／該高度的個人有人校正壓力kPa；大於等於門檻判有人，三通道至少兩票有人則多數決判有人。兩種判定均要求完整有效的三通道資料，缺資料不當作空枕。

| 高度組別 | Monitor門檻 | Neck門檻 | Head門檻 |
| --- | --- | --- | --- |
| 姿勢一高度 | 0.48 | 0.27 | 0.45 |
| 姿勢五高度 | 0.63 | 0.75 | 0.67 |

規則為 `EXP04_LOAD_RATIO_FULL30_20261027_V1`，使用全30人資料重估的候選門檻，不利用本輪空枕重新調參；多數決的實測表現仍需驗證。來源路徑、雜湊及換算係數見 [occupancy-recorder.js](spp3_BLE/occupancy-recorder.js)。完整操作、補測及12／13欄定義見 [實驗四使用說明](實驗四使用說明.txt)。

## 輸出檔案與時間

以下以S01為例；`<run_id>`為輪次識別碼，`<匯出毫秒>`為匯出時的Unix毫秒時間。

| 實驗 | 檔案名稱與內容 |
| --- | --- |
| 01 | `S01_pose5_height5_still_<run_id>.csv`及同名PNG；依實際條件替換姿勢、高度及still／movement。CSV為48欄，包含受測者／條件、時間、壓力、兩模型結果及狀態；校正總覽為`S01_01_00_校正總覽.svg` |
| 02 | `S01_00_校正總覽.svg`；每方法一份如`S01_姿勢一_R.svg`，包含目標、實測壓力、控制資料及評分；此區沒有逐秒實驗CSV |
| 03 | `S01_03_<匯出毫秒>_逐秒分類.csv`（41欄）、`_壓力與分類事件.csv`（40欄）、`_結果總覽.svg`及各輪`_輪次01_壓力曲線.png`；校正總覽為`S01_03_00_校正總覽.svg` |
| 04 | 每高度各有`S01_EXP04_姿勢五高度_分段30秒.csv`（12欄）、`_連續紀錄.csv`（13欄）、`_壓力曲線.png`及`_結果總覽.svg`；另一組改為「姿勢一高度」。校正總覽為`S01_04_00_校正總覽.svg`，檔名不含時間 |

實驗04可單獨「匯出目前高度CSV」，也可「儲存全部結果」保留圖片及SVG內的精確按鈕／事件資訊；沒有另輸出事件CSV。同高度補測輪次累積匯出，同名檔覆寫前會確認。不同受測批次請分開資料夾。

| 資料 | 時間與缺值含義 |
| --- | --- |
| 01 | `elapsed_s＝裝置sequence−1`（0～34）；另保存電腦接收時間與裝置tick／sample時間。補取保留原序號與壓力／分類對應 |
| 03 | 從Web按開始計時，按接收時間分成第1～20秒；壓力事件與分類事件有各自接收時間，分類列保存模型使用的ADC |
| 04 | `timestamp`為電腦本機接收時間，格式`YYYY/MM/DD-HH:mm:ss.SSS`；缺資料秒格時間留空。段長以單調時鐘計算，P封包沒有裝置取樣時間 |

電腦日期時間不是ESP32取樣時間的精確同步。缺值、無效與暖機應依欄位判讀，不能以畫面有數字就當成當秒成功分類。

**實驗01／03的沿用只影響畫面**：明確收到`INVALID`時，使用同輪、同session、各模型上一筆有效結果與機率，標出來源及經過時間；尚無有效結果、暖機或缺訊息不補。CSV及有效筆數仍使用原始資料，壓力不補值；實驗03結果SVG也保留原始狀態。

## 版面與常見狀況

實驗區可用寬度達1000px時，實驗03上方為受測者／校正，左下為操作、右下為曲線與結果；實驗02左側為受測者／校正、右側為操作。實驗04上方並排受測者與兩姿勢校正，對齊兩側標題及儲存按鈕。測試區和紀錄區依序占下方整列，展開紀錄時，寬版曲線與分段表並排。窄視窗上下排列，長表格在區塊內捲動。

主頁頂端的「線圖監測」按鈕可收合或展開整個監測區。收合時，實驗操作區使用完整可用寬度，壓力資料接收及實驗記錄持續。重新展開會恢復欄寬及原有線圖模式，桌面版可拖曳中間分隔線再次調整。瀏覽器會記住收合狀態。監測區裡的「收合線圖」及「收合資訊」分別只控制各自的內容。

| 狀況 | 處理方式 |
| --- | --- |
| 校正逾時 | 確認姿勢、高度與新壓力；01／03需等待裝置取消及恢復完成，重新勾選後再校正。舊卡片不代表本次成功 |
| 開始按鈕停用 | 依提示核對連線、使用者資料、兩組校正、目前高度、確認勾選、前輪完成／儲存及資料夾要求 |
| 有歷史模型顯示暖機 | 前6筆有效樣本建立歷史；無效秒不增加歷史，不等於固定第7秒必定有結果 |
| 斷線、氣囊作業失敗或高度不符 | 停止正式流程並保存可用部分資料；重新確認裝置狀態後重試，不自動續接 |
| 匯出失敗或只看到部分檔案 | 頁面資料保留供重試；確認資料夾權限及所有檔案保存成功後再離開，多檔寫入不是整批交易 |
