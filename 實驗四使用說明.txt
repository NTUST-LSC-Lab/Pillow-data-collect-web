實驗四：兩組高度、五種睡姿的躺枕／離枕偵測

畫面配置
寬版在上方並排受測者與校正，測試和紀錄依序在下方。窄版改為上下排列。
正式頁頂端的「線圖監測」可收合整個監測區，讓實驗操作區使用完整可用寬度。
壓力接收及實驗記錄仍會持續，重新展開會恢復欄寬。

固定操作順序
姿勢一校正 → 姿勢五校正 → 姿勢五高度測試 → 抽乾並設定姿勢一高度 → 姿勢一高度測試 → 儲存。
每組高度均依序測試姿勢一至五；睡姿按鈕只標記實際狀態，不會改變氣囊高度。
沒有初始空枕30秒，也沒有5分鐘延伸段。

一、校正與準備
1. 連線ESP32，等待正常開機完成，設定個人資料、受測者編號及儲存資料夾。
2. 完成姿勢一校正，保存Head／Neck高度與三通道有人壓力。
3. 完成姿勢五校正，保存另一組高度與三通道有人壓力，再儲存校正總覽。
   EXP4使用Web收到的完整三通道P壓力校正快照，不啟動EXP3雙模型分類。
4. 保留姿勢五高度。兩組基準、目前高度與近期有效壓力通過檢查後，才可開始。

二、姿勢五高度測試
1. 按「開始姿勢五高度測試」只啟用狀態按鈕，尚未開始記錄或計時。
2. 請受測者以姿勢一躺下；頭頸由枕頭承載時按「姿勢一」，才開始連續記錄與本段30秒計時。
3. 躺枕滿30秒後，請受測者離枕；頭頸完全離開時按「離開枕頭」，開始空枕30秒。
4. 空枕滿30秒後，請受測者以姿勢二躺下，承載時按「姿勢二」。依此類推至姿勢五。
   順序為：姿勢一30秒 → 離枕30秒 → 姿勢二30秒 → 離枕30秒 →
           姿勢三30秒 → 離枕30秒 → 姿勢四30秒 → 離枕30秒 → 姿勢五30秒 → 離枕30秒。
5. 最後一次離枕滿30秒、畫面顯示5／5完成後，按「結束本高度測試」停止此輪記錄。
6. 可按「匯出目前高度CSV」，先保存姿勢五高度的兩份CSV。

三、切換高度並完成第二組
1. 受測者保持離枕，勾選確認後按「抽乾並設定姿勢一高度」。
2. Web沿用EXP02,DRAIN與HEIGHT_DRY，等待逐顆抽乾、恢復開機高度，再設定已保存的姿勢一高度。
   收到裝置完成回覆並核對高度後，才開放第二組開始；不重新開機、不重取或覆蓋兩組校正。
3. 按「開始姿勢一高度測試」啟用按鈕，再以姿勢一躺下並按「姿勢一」開始記錄。
4. 完整重複五種睡姿及其後離枕30秒，最後按「結束本高度測試」。
5. 可單獨匯出目前高度CSV，或按「儲存全部結果」保存兩組高度的CSV、PNG及SVG。
兩組固定停留共10分鐘；校正、充放氣與動作另計，先以每人15～20分鐘安排，再由預試確認。

計時、人工標記與判定
- 按不同狀態立即結束前段、開始新段；重複按目前狀態不重設計時。
- 滿30秒提示並嘗試播放提示音，畫面計時停在30秒，不會自動切換睡姿或離枕。
- 分段CSV只保留每段前30秒；連續CSV仍持續記錄等待時間，並持續判斷有人／空枕。
  例如姿勢一維持到第35秒才按離枕：分段CSV保留前30秒，連續CSV另保留後5秒等待資料。
- 按鈕是操作者提供的實際label，與兩種偵測結果獨立；等待期間沿用上一個label。
- 校正比例＝目前壓力kPa／該受測者在目前高度的有人校正壓力kPa。
  Monitor單獨判定與三通道多數決使用同一筆有效資料，門檻按高度組別選取。
- 固定規則版本EXP04_LOAD_RATIO_FULL30_20261027_V1；門檻依Monitor／Neck／Head順序：
  姿勢五高度：0.63／0.75／0.67；姿勢一高度：0.48／0.27／0.45。
  比例大於等於門檻判有人；三通道均有效時，至少兩票有人即為多數決有人。
  門檻為全30人refit候選，不用本輪空枕資料調參；多數決組合仍待實驗驗證。來源詳見README。

未完成、補測及異常
- 未滿30秒切換、錯序或重測都照實保存，不覆蓋舊段。
  只有當前待測姿勢滿30秒，緊接的離枕段也滿30秒，才推進完成進度。
- 斷線、中止或個人資料／高度／安全狀態變更時停止本輪，保留部分資料，不自動續跑。
  重新確認狀態、保持離枕，按「重新確認目前高度，準備補測」；高度不符需先恢復。
  依畫面提示的待補測姿勢重新開始，新段重新計時30秒，不接續未完成段。
- 抽乾／充氣失敗或完成回覆逾時時，不會開放第二組開始；確認裝置狀態後重新抽乾。
- 滿30秒不保證有30筆有效資料；缺資料或無效資料另行標示，不當作空枕、不以舊值補秒。

輸出檔案
每個高度各兩份CSV：
1. 分段30秒.csv：依每次狀態按鈕切段，只保留該段前30秒。
2. 連續紀錄.csv：從首次狀態標記記到本輪結束或中止，包含超過30秒的等待與持續判定。
   兩檔均按秒輸出，每個秒格取最後一筆新壓力；共同資料列完全相同。
   完整接收樣本留在本頁記憶體供壓力圖使用，CSV不是每一筆BLE封包的清單。
分段CSV共12欄，依序為：
timestamp,actual_state,segment_second,monitor_kpa,neck_kpa,head_kpa,monitor_ratio,neck_ratio,head_ratio,monitor_result,majority_result,data_status
連續CSV另加最後一欄record_phase，共13欄；不再另外輸出事件CSV。
- timestamp：電腦收到完整壓力的本機時間，YYYY/MM/DD-HH:mm:ss.SSS；缺資料格留空。
- actual_state：姿勢一～五／離開枕頭，由操作者按鈕決定。
- segment_second：距本次標記的秒數，保留3位小數；缺資料格填該秒格起點。
- *_kpa：目前三通道壓力；*_ratio：各自的目前kPa／有人校正kPa。
- monitor_result、majority_result：有人／空枕；資料無效或缺資料時留空。
- data_status：有效／缺資料／無效。
- record_phase：本段30秒內／30秒後等待，僅連續CSV有此欄。

檔名不放日期時間，以S01為例：
S01_EXP04_姿勢五高度_分段30秒.csv
S01_EXP04_姿勢五高度_連續紀錄.csv
S01_EXP04_姿勢五高度_壓力曲線.png
S01_EXP04_姿勢五高度_結果總覽.svg
S01_EXP04_姿勢一高度_分段30秒.csv
S01_EXP04_姿勢一高度_連續紀錄.csv
S01_EXP04_姿勢一高度_壓力曲線.png
S01_EXP04_姿勢一高度_結果總覽.svg
校正總覽另存S01_04_00_校正總覽.svg；完整兩高度共4份CSV、2張PNG、2份結果SVG，加上校正總覽共9檔。
預覽檔名另有SIMULATED_標記，示範下載可能再加DEMO_，不可與實機資料混用。

儲存與時間
- 「匯出目前高度CSV」只保存該高度的兩份CSV；「儲存全部結果」另含各高度壓力PNG與結果SVG。
- 同高度補測與未完成輪次一併累積匯出。中途可儲存快照，儲存不會停止連續記錄。
- 同名檔案存在時先確認整批覆寫；取消不改檔案。不同受測／實驗批次請分開資料夾。
  寫入失敗會保留頁面資料供重試，多檔寫入不是整批交易；離開或重新整理前確認儲存成功。
- 結果SVG的exp04-records metadata保留校正、規則、輪次、各段精確按鈕時間與事件，CSV不重複增加這些欄位。
  需要完整追溯時請用「儲存全部結果」，只匯出CSV不會另生成SVG。
- CSV日期時間來自電腦系統時鐘；段長使用performance.now()，自動校時不改變30秒長度。
  P壓力封包沒有ESP32取樣時間；此時間是Web接收時間，不能當成與ESP32取樣精確同步。
